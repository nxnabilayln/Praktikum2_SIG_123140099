## 📌 Deskripsi Praktikum

Praktikum ini merupakan lanjutan dari Praktikum 1 dengan menambahkan tipe data spasial LineString dan Polygon menggunakan PostgreSQL dan PostGIS.  

Tabel yang dibuat:
- `jalan` (LineString)
- `wilayah` (Polygon)

Dilakukan konversi format menggunakan:
- ST_AsText()
- ST_AsGeoJSON()
- ST_IsValid()

Seluruh data divisualisasikan di QGIS dengan layer terpisah.
